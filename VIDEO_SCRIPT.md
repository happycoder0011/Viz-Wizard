# Viz-Wizard Demo Video Script

## Duration: 60-90 seconds

---

## Scene 1: The Problem (5 seconds)
**Voiceover:** "Ever joined a new team and spent days trying to understand the codebase?"

*Show: A wall of text/folder structure in VS Code looking overwhelming*

---

## Scene 2: The Solution Reveal (10 seconds)
**Voiceover:** "What if you could see the entire architecture at a glance?"

*Action:*
1. Open Viz-Wizard (localhost:3000)
2. Show the beautiful 3D city visualization loading
3. Pause to let the visual impact sink in

---

## Scene 3: Navigation Demo (15 seconds)
**Voiceover:** "Every building is a file. Every district is a module. Zoom in to explore."

*Action:*
1. Slowly zoom in using scroll wheel
2. Pan around the city
3. Show buildings changing detail levels as you zoom
4. Hover over a few buildings to show tooltips

---

## Scene 4: File Exploration (15 seconds)
**Voiceover:** "Click any file to see its details - complexity, connections, dependencies."

*Action:*
1. Click on a colorful building (core file)
2. Show the SelectedBuildingPanel appearing on the left
3. Point out: line count, complexity score, category
4. Show the connection lines highlighting

---

## Scene 5: Code Editor (15 seconds)
**Voiceover:** "Want to see the actual code? One click."

*Action:*
1. Click "View Code" button
2. Code editor opens with syntax highlighting
3. Show the Chat Panel on the right side
4. Select a few lines of code in the editor

---

## Scene 6: AI Chat (15 seconds)
**Voiceover:** "Don't understand something? Ask the AI. It has full context of your code."

*Action:*
1. Show selected code indicator in chat panel
2. Click "Explain this" quick action
3. (If you have API key) Show AI response
4. Or just show the chat interface ready to use

---

## Scene 7: Critical Path Radar (10 seconds)
**Voiceover:** "Find the files that matter most - the critical 5% causing 80% of issues."

*Action:*
1. Click the "Critical Path" button in header
2. Watch buildings turn gold/grayscale
3. Show the bottom panel with risk scores
4. Click on a critical file card

---

## Scene 8: Call to Action (5 seconds)
**Voiceover:** "Viz-Wizard. Explore any codebase in seconds. No download required."

*Action:*
1. Zoom out to show full city
2. Fade to logo/URL

---

## Recording Tips

1. **Resolution:** Record at 1920x1080 or higher
2. **Browser:** Use Chrome in full screen, hide bookmarks bar
3. **Speed:** Move slowly and deliberately
4. **Cursor:** Make cursor movements smooth
5. **Pause:** Hold on key moments for 1-2 seconds

## Tools to Record

**Mac:**
- QuickTime Player → File → New Screen Recording
- Or use Loom (free tier available)
- Or OBS Studio (free, more control)

**Post-production:**
- Speed up slow parts to 1.5x
- Add smooth transitions between scenes
- Add subtle background music (lo-fi or ambient tech)
